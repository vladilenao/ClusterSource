# SPEC-0007: Открытый интерес

**Статус:** Черновик · **Обновлено:** 2026-10-12 · **Зависит от:** SPEC-0003

## Зачем

Открытый интерес (ОИ) по фьючерсам — классический фильтр к объёму: рост цены
при растущем ОИ означает приток новых денег, рост при падающем ОИ — закрытие
шортов. Источники уже доступны без подписки:

- **T-Invest, реальное время:** `SubscribeTradesRequest(with_open_interest=true)`.
  В стриме приходят сообщения `OpenInterest {instrument_uid, time,
  open_interest, ticker, class_code}`, только для фьючерсов. Поле есть в
  установленном SDK 1.49.3.
- **ISS, задержка 15 минут, по каждой сделке:** `OPENPOSITION` в ленте FORTS
  (SPEC-0003).

## Делаем / Не делаем

**Делаем:**
- флаг `with_open_interest` в существующей подписке и хранение ряда ОИ;
- ОИ после каждой сделки из ISS и разметку сделки:
  ΔОИ = +количество — открытие позиций обеими сторонами,
  ΔОИ = −количество — закрытие,
  ΔОИ = 0 — передача позиции;
- события ОИ для SPEC-0008: всплеск ОИ, квадрант «цена × ОИ», перетекание ОИ
  при ролловере непрерывного фьючерса.

**Не делаем:**
- `futoi` (ОИ физлица/юрлица) — по найденным данным он доступен только по
  подписке; отложено вместе с решением о подписке.

## Гарантии

- **G-1.** Ряд ОИ ДОЛЖЕН подчиняться тем же статусам качества, что и сделки (SPEC-0001).
- **G-2.** Для непрерывного фьючерса ОИ ДОЛЖЕН браться у того же контракта,
  что и сделки (`config.nearest_contract`, инвариант A11). Ролловер
  публикуется событием.

## Данные и контракты

- Новая таблица ряда ОИ в SQLite инструмента и колонка ОИ в Parquet ISS-сделок FORTS.
- `docs/contracts/asyncapi/t-invest-market-data-stream.asyncapi.yaml`: сообщение `open_interest`.
