# SPEC-0007: Открытый интерес

**Статус:** Готово (ждёт перезапуска сервиса) · **Обновлено:** 2026-10-13 · **Зависит от:** SPEC-0003, 0005, 0009

## Зачем

Открытый интерес (ОИ) по фьючерсам — классический фильтр к объёму: рост цены
при растущем ОИ означает приток новых денег, рост при падающем ОИ — закрытие
шортов. Источники доступны без подписки:

- **T-Invest, реальное время:** `SubscribeTradesRequest(with_open_interest=true)`;
  в стриме — сообщения `OpenInterest {instrument_uid, time, open_interest}`
  (только UID, без FIGI; только фьючерсы).
- **ISS, задержка 15 минут, по каждой сделке:** `OPENPOSITION` в ленте FORTS
  (SPEC-0003).

### Исследование 2026-10-13

- **Стрим** (60 с, 12 контрактов, вечерняя сессия): подписка подтверждена с
  `with_open_interest = true` у всех; 287 сделок и 87 сообщений ОИ —
  сообщение приходит **только при изменении** ОИ (NG: 148 сделок, 52
  сообщения), со своим временем.
- **Лента ISS** (1 931 727 сделок FORTS за день): изменение ОИ между
  соседними сделками контракта **всегда чётное** — Мосбиржа считает
  открытые позиции обеих сторон:

  | ΔОИ | Смысл | Доля |
  |-----|-------|------|
  | 0 | передача позиции | 47,1% |
  | +2 × количество | обе стороны открыли | 25,5% |
  | −2 × количество | обе стороны закрыли | 22,2% |
  | \|ΔОИ\| < 2 × количество | одна сторона открыла, другая закрыла | 4,2% |
  | \|ΔОИ\| > 2 × количество | ОИ изменили сделки вне анонимной ленты (L-14) | 1,0% |

## Делаем / Не делаем

**Делаем:**
- флаг `with_open_interest` в общей подписке хаба; маршрут сообщений ОИ по
  `instrument_uid`; ряд ОИ в SQLite инструмента (`open_interest`), пишет
  консьюмер; хранится 7 дней, как горячие тики;
- `RECNO` в ленте ISS (порядок заключения сделок FORTS);
- поток ОИ по ленте ISS: по барам — открыто, закрыто, передано, вне ленты,
  ОИ на конец бара (`reader.get_oi_flow`);
- активный контракт непрерывного фьючерса по дням (`reader.get_contract`):
  записывает сверка (SPEC-0005), она знает тикер ленты.

**Не делаем:**
- события ОИ (всплеск, квадрант «цена × ОИ», перетекание при ролловере) —
  слой сигналов, SPEC-0008;
- `futoi` (физлица/юрлица) — только по подписке.

## Правила

Разметка сделки по ленте (сделки контракта в порядке `RECNO`; ΔОИ — разница
`OPENPOSITION` с предыдущей сделкой контракта, q — количество):

- открыто = max(ΔОИ, 0) / 2, закрыто = max(−ΔОИ, 0) / 2 (в пределах q);
- передано = q − |ΔОИ| / 2 (не меньше 0);
- вне ленты = (|ΔОИ| − 2q) / 2, если |ΔОИ| > 2q: изменение ОИ сделками,
  которых в ленте нет.

## Гарантии

- **G-1.** Ряд ОИ из стрима подчиняется тем же статусам качества, что и сделки
  инструмента (одно соединение, SPEC-0004): минута `DEGRADED` — и ОИ в ней
  недостоверен. Поток ОИ по ленте ISS достоверен для дней с полной лентой (SPEC-0003).
- **G-2.** Для непрерывного фьючерса ОИ ДОЛЖЕН браться у того же контракта,
  что и сделки (одна подписка; `get_contract` — по сверке).
- **G-3.** Продюсер не пишет ОИ в БД (A2): копит в памяти, пишет консьюмер.

## Данные и контракты

```sql
-- SQLite инструмента
CREATE TABLE open_interest (ts TEXT NOT NULL, value INTEGER NOT NULL);  -- индекс по ts
-- _iss.sqlite3
ALTER TABLE iss_trades ADD COLUMN recno INTEGER;  -- FORTS RECNO; Parquet — та же колонка
```

Активный контракт — `meta['contract:YYYY-MM-DD']` в SQLite инструмента.
Контракт стрима: `with_open_interest: true` и сообщение `open_interest`.

## Открытые вопросы

- [x] Как часто T-Invest присылает ОИ — при каждом изменении (не на каждую сделку).
- [x] Совпадает ли ОИ T-Invest с `OPENPOSITION` ISS — да: 87 из 87 сообщений стрима (18:46–18:47 UTC 2026-10-13, 12 контрактов) равны `OPENPOSITION` сделки той же секунды в ленте ISS.

## Журнал решений

- **2026-10-13** — ОИ реализуем на бесплатных источниках; `futoi` отложен.
- **2026-10-13** — ОИ стрима и `OPENPOSITION` ленты ISS совпадают точно (87 из 87): один и тот же показатель биржи, реальное время и задержка 15 минут.
- **2026-10-13** — По исследованию: ΔОИ на Мосбирже = ±2 × количество (позиции обеих сторон); разметка — по формулам выше, с отдельной колонкой «вне ленты». События ОИ — в SPEC-0008.
