# SPEC-0010: Защита от сна Mac во время сбора

**Статус:** Готово · **Обновлено:** 2026-10-13 · **Зависит от:** —

## Зачем

Пока Mac спит, сбор стоит целиком: стрим T-Invest, лента ISS, запись.
2026-10-13 детекторы SPEC-0004 показали дыру у всех инструментов с 08:08 до
08:23 МСК; журнал питания (`pmset -g log`) подтвердил: Mac уснул в 08:08:27 и
проснулся в 08:21:18, работая от батареи. Сон по простою настроен на 1 минуту.

## Делаем / Не делаем

**Делаем:** при старте на macOS процесс запускает `caffeinate -i -w <свой PID>`
— запрет сна по простою, который действует ровно пока жив процесс (и
снимается сам при любом его завершении). Отключается `keep_awake: false`.

**Не делаем:**
- не меняем системные настройки питания (`pmset`);
- закрытие крышки ноутбука по-прежнему усыпляет Mac (кроме режима с
  внешним монитором и питанием) — это ограничение L-13; надёжное решение —
  машина, которая не спит.

## Гарантии

- **G-1.** На macOS при `keep_awake: true` (по умолчанию) процесс сбора ДОЛЖЕН
  держать запрет сна по простою всё время своей работы.
- **G-2.** Запрет НЕ ДОЛЖЕН переживать процесс: он привязан к PID (`-w`).
- **G-3.** Невозможность запустить `caffeinate` НЕ ДОЛЖНА останавливать сбор:
  предупреждение в логе.

## Наблюдаемость

- `Сон по простою запрещён, пока работает процесс (caffeinate, PID N)` (INFO).
- `caffeinate не найден …` / `Не удалось запретить сон …` (WARNING).
- Проверка: `pmset -g assertions | grep caffeinate`.
