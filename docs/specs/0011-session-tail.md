# SPEC-0011: Хвост вечерней сессии по свечам ISS

**Статус:** Готово (ждёт перезапуска сервиса) · **Обновлено:** 2026-10-14 · **Зависит от:** SPEC-0003, 0005, 0006

## Зачем

Бесплатная лента ISS (SPEC-0003) отдаёт сделки с задержкой 15 минут, но в
полночь МСК окно задержки обрывается: последние минуты вечерней сессии
(23:45–23:50 МСК) в ленте не появляются никогда. Из-за этого лента дня всегда
неполная, фьючерсы не могут получить `FINAL` (SPEC-0006), а
`ISS_DAY_INCOMPLETE` пишется каждый день.

### Исследование 2026-10-14 (торговый день 13.10)

- Последний опрос до полуночи (23:59:41) получил сделки до 23:44:37; с 00:00
  до 06:42 ни один опрос не дал новых сделок. Лента обрывается: акции —
  23:44:32, FORTS — 23:44:37 МСК.
- Недостача ленты против итогов — ровно хвост после среза: OZON 405, YDEX
  284, CHMF 277, GAZP 237 сделок. Архив T-Invest за день совпал с итогами
  ISS точно (OZON 103 789 = 103 789).
- До среза наши данные совпали с лентой сделка в сделку (число и объём): Si
  191 950, BR 91 288, CR 183 060, GAZP 145 188.
- Минутные свечи ISS (`candles.json?interval=1`) за хвост доступны утром
  следующего дня; объём, максимум и минимум каждой минуты 23:44–23:49
  совпали с нашими у Si, BR, OZON, GAZP. Объём свечи акций — в штуках
  (наши лоты × `lot_size`).
- В ленте FORTS нет календарных спредов (`BRX6BRZ6`: 8 319 сделок в
  итогах, 0 в ленте) — `ISS_DAY_INCOMPLETE` из-за них ложный.
- FORTS 13.10 получил `ARCHIVE_CONSISTENT` в 00:40, до того как лента дня
  была учтена, и больше не перепроверялся бы.

## Делаем / Не делаем

**Делаем:**
- ночью, в проверке FINAL, хвост каждого дня с лентой сверяется с минутными
  свечами ISS; минуты хвоста получают вердикты;
- `FINAL` фьючерсов: голова дня — по ленте сделка в сделку, хвост — по
  свечам, с пометкой в справке дня «хвост по свечам»;
- недавние `ARCHIVE_CONSISTENT` перепроверяются (лента и свечи могли прийти позже);
- проверка полноты ленты (SPEC-0003 G-5) учитывает хвост и не считает спреды;
- попутно: верное сообщение, когда архив T-Invest за вчера ещё не
  опубликован; при старте стрим открывается первым, всё обслуживание — в фоне.

**Не делаем:**
- платный доступ к ISS (решение 2026-10-12);
- сверку хвоста по числу сделок: в свечах его нет. Объём и диапазон цен
  каждой минуты совпадают — этого достаточно для `FINAL` (решение 2026-10-14);
- подтверждение сигналов в хвосте в реальном времени: оно невозможно (SPEC-0008).

## Правила

**Срез ленты** рынка за торговый день D — время последней сделки ленты ISS с
`trade_date = D`. **Хвост** — минуты от минуты среза (включительно; она
попала в ленту частично) до конца дня.

**Хвост — разрыв публикации ISS**, только если он не длиннее 20 минут (15
минут задержки + запас): последняя наша сделка дня позже начала хвоста не
больше чем на 20 минут. Иначе лента не покрывает день (сбор отставал или
стоял) — день проверяется как без ленты (`ARCHIVE_CONSISTENT` / `MISMATCH`).

**Сверка хвоста по свечам.** Для каждой минуты хвоста, где есть наши сделки
или свеча ISS: объём (у акций — × `lot_size`), максимум и минимум цены
совпали — минута `CANDLE_VERIFIED`, иначе `GAP` (`candle_mismatch`). Свечей
нет совсем при наших сделках в хвосте — хвост недоступен: вердикта дня нет,
повтор следующей ночью; через 3 суток — как без ленты.

**FINAL фьючерсов** (уточняет SPEC-0006): лента дня есть, её статус не
`incomplete`, хвост — разрыв публикации:

| Голова (до начала хвоста) | Хвост | Статус |
|---------------------------|-------|--------|
| наши = лента (число и объём) | все минуты `CANDLE_VERIFIED` | `FINAL`, эталон `iss_tape`, справка «хвост по свечам с ЧЧ:ММ МСК: n сделок / v» |
| не совпала | — | `MISMATCH` (перекачка) |
| совпала | есть `GAP` | `MISMATCH` (перекачка) |
| совпала | недоступен | без вердикта, повтор (до 3 суток) |

**Акции:** `FINAL` по-прежнему по дневным итогам (они покрывают и хвост);
хвост сверяется по свечам для минутных вердиктов, на статус дня не влияет.

**Перепроверка:** `ARCHIVE_CONSISTENT` моложе 3 суток проверяется заново
каждую ночь; `FINAL` не перепроверяется.

**Полнота ленты (уточняет SPEC-0003 G-5).** По каждой бумаге лента не больше
итогов, срез рынка не раньше 23:30 МСК торгового дня, календарные спреды
FORTS не учитываются. Недостача против итогов — хвост и сделки вне анонимной
ленты, пишется справкой. Полнота по нашим инструментам доказывается сверкой
(SPEC-0005) и ночным FINAL.

## Гарантии

- **G-1.** `FINAL` фьючерсов ДОЛЖЕН ставиться только при точном совпадении
  головы дня с лентой ISS и совпадении каждой минуты хвоста со свечами ISS
  (объём, максимум, минимум); справка дня ДОЛЖНА содержать «хвост по свечам».
- **G-2.** Хвост длиннее 20 минут НЕ ДОЛЖЕН подтверждаться свечами: такой
  день проверяется как день без ленты.
- **G-3.** Недоступность свечей НЕ ДОЛЖНА давать окончательный вердикт в
  первые 3 суток.
- **G-4.** Хвост сессии и календарные спреды НЕ ДОЛЖНЫ давать
  `ISS_DAY_INCOMPLETE`; лента больше итогов или срез раньше 23:30 МСК — ДОЛЖНЫ.
- **G-5.** Стрим ДОЛЖЕН открываться до обслуживания хранилища при старте;
  стартовое обслуживание НЕ ДОЛЖНО дописывать текущий день (его пишет стрим,
  пропуски до старта дозаливает сверка SPEC-0005).

## Данные и контракты

- `minute_verdicts.status` — новое значение `CANDLE_VERIFIED`; `GAP` с
  `detail = candle_mismatch: …` (`stream_n` — наши сделки минуты, `iss_n` = 0).
- `day_verdicts.detail` фьючерсов — «хвост по свечам с ЧЧ:ММ МСК: n сделок / v; …».
- ISS: `GET /iss/engines/{engine}/markets/{market}[/boards/TQBR]/securities/{SECID}/candles.json?interval=1&from=&till=`
  (`docs/contracts/openapi/moex-iss.openapi.yaml`); время свечей — МСК.

## Наблюдаемость

- `TAIL X D: хвост с ЧЧ:ММ МСК, минут m — совпал со свечами` (INFO).
- `TAIL_MISMATCH X D: минуты …` (ERROR) — хвост не совпал со свечами.
- `TAIL_UNAVAILABLE X D: свечей ISS нет` (WARNING) — повтор следующей ночью.
- `ISS_DAY_VERIFIED … ; не в ленте N сделок (хвост после ЧЧ:ММ МСК и вне анонимной ленты)` (INFO).
- `Архив истории за D для X ещё не опубликован — отметка сохранена` (INFO).
