# SPEC-0008: Торговые сигналы по объёмам

**Статус:** Черновик · **Обновлено:** 2026-10-12 · **Зависит от:** SPEC-0001, 0004, 0005, 0006, 0007

## Зачем

Робот получает уведомления о значимых событиях в объёмах сделок. Все сигналы
подчиняются контракту и гарантиям SPEC-0001.

## Каталог сигналов

### Лента (реальное время), класс `fast`

| Сигнал | Детектирование |
|--------|----------------|
| Крупная агрессивная заявка | Склеить сделки с одинаковым временем и стороной в «родительскую» заявку; порог — перцентиль 99–99,9 размера в рублях (`price × volume × lot_size`) по `FINAL`-дням, отдельно для каждого инструмента |
| Sweep | Одна сторона, одно время, цена монотонно прошла ≥ k шагов цены |
| Всплеск объёма (RVOL) | Объём за минуту относительно обычного объёма **на это же время дня** (не скользящей средней) |
| Перекос дельты | \|delta\| / volume за окно выше порога при значимом объёме |

### Кластеры (на закрытии бара), класс `level`

| Сигнал | Смысл |
|--------|-------|
| Stacked imbalance (диагональный) | Покупки на P против продаж на P − шаг ≥ 3:1 на 3+ уровнях подряд |
| Поглощение | Большой агрессивный объём на уровне без продолжения цены |
| Истощение / незавершённый аукцион | Почти нет объёма на экстремуме бара |
| Дивергенция кумулятивной дельты | Новый экстремум цены без подтверждения CVD |
| POC на экстремуме бара | Максимальный объём на хае или лое свечи |

### Сессия, класс `level`

Пробой и принятие цены за пределами Value Area прошлого дня; тест голого POC;
дневной RVOL; пересечение VWAP на объёме.

### Межинструментальные

Фьючерс опережает акцию; ширина потока по корзине индекса; синхронный
всплеск по многим тикерам (макро-событие); ротация секторов.

### Открытый интерес (SPEC-0007)

Всплеск ОИ; квадрант «цена × ОИ»; доля открывающих/закрывающих сделок.

## Обязательные фильтры

- Аукционы открытия и закрытия (`PERIOD` ISS, сделки `UNKNOWN`) не считаются
  агрессией и не входят в дельту, но входят в объём.
- Клиринг срочного рынка, утренняя, основная и вечерняя сессии, **сессии
  выходного дня** — базовые уровни отдельно для каждого режима.
- Пороги только адаптивные и в рублях; база — окно `reader.get_baseline_days` (SPEC-0006): последние 20 `FINAL`-дней, добор `ARCHIVE_CONSISTENT`; в каждом сигнале — `baseline_quality` (`pure` / `mixed`) и состав окна (`baseline_days: {final, archive}`).
- Кластерные сигналы несут `bar_closed`.
- Детекторы с точностью меньше секунды не работают на `REPAIRED`-секундах (SPEC-0005).

## Порядок (MVP)

1. Крупная агрессивная заявка. 2. RVOL. 3. Stacked imbalance. 4. Поглощение.
Остальное — после проверки на истории (частота срабатываний и поведение цены после).

## Гарантии

- **G-1.** Каждый сигнал ДОЛЖЕН соответствовать контракту SPEC-0001 (конверт, итог проверки, G-1…G-3).
- **G-2.** Детекторы сигналов читают тики из очереди коллектора (разветвление
  потока), а не из SQLite, чтобы задержка не зависела от интервала записи.
