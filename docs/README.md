# Документация ClusterSource

ClusterSource — сервис сбора тиковых данных (обезличенных сделок) из API
T-Investments с гибридным хранением: SQLite («горячее», последние 7 дней) +
Parquet («холодное», история). Данные потребляет торговый робот через
функцию построения footprint-матрицы `get_cluster_data()`.

## Конвенции документации

- **Источник истины — код** в `src/cluster_source/`. Документация описывает
  фактическое поведение. Действующие ограничения имеют идентификатор `L-NN`,
  исправленные расхождения — `KI-NN`; оба списка ведутся в
  [12-known-issues.md](12-known-issues.md).
- Все время — **UTC**. «День» — календарные сутки UTC `[00:00, 24:00)`.
- `today` — полночь текущих суток UTC; `today-N` — полночь на N суток раньше.
- Имена в `моноширинном` шрифте совпадают с идентификаторами в коде.

## Глоссарий

| Термин | Определение |
|--------|-------------|
| Тик | Одна обезличенная сделка: время, цена, объём (в лотах), направление, идентификатор. В коде — `Tick`. |
| Горячее хранилище | SQLite-файл инструмента `data/history/_sqlite/{storage}.sqlite3`, таблица `ticks_hot_store`, режим WAL. |
| Холодное хранилище | Parquet-файлы инструмента `data/history/{storage}/{YYYY-MM-DD}.parquet`, один файл на день. |
| `storage_name` (ключ хранения) | Имя каталога/файлов и значение колонки `ticker`. Для `continuous_futures` — `{id}_CONTINUOUS`, иначе `id`. |
| Непрерывный фьючерс | Логический инструмент (`Si`, `RI`, …), который в каждый момент отображается на ближайший к экспирации контракт, а данные пишутся под одним ключом `{id}_CONTINUOUS`. |
| FIGI | Идентификатор инструмента в T-Investments; используется для подписки на стрим и `GetLastTrades`. |
| Ключ архива (`TICKER_CLASS`) | Параметр `instrumentId` сервиса `history-trades`, например `SBER_TQBR`, `SiZ6_SPBFUT`. |
| Догрузка (backfill) | Скачивание дней, которых нет ни в одном хранилище, при старте и в ночном обслуживании. |
| Перекачка | Замена данных неполного (отмеченного) дня данными официального архива. |
| Ночное обслуживание | Догрузка + архивация по расписанию `archiver.*` (по умолчанию 00:05 UTC) и при старте. |
| Архивация | Перенос дня из SQLite в Parquet с последующей очисткой SQLite за окном удержания. |
| Footprint / кластер | Матрица «интервал времени × цена» с объёмами покупок и продаж. |
| Delta | `buy_volume − sell_volume` в ячейке footprint. |
| COMPROMISED | Маркер в логе: в потоке обнаружен разрыв числовых `trade_id`; день отмечается для перекачки. |
| Отметка для перекачки | Строка таблицы `days_to_refresh`: день неполон (`stream_gap`, `compromised`, `partial_backfill`) или сохранён до биржевого фильтра (`dealer_cleanup`). |
| Биржевая / дилерская сделка | Биржевая — сделка Мосбиржи (`TRADE_SOURCE_EXCHANGE`); дилерская — сделка внутреннего рынка Т-Банка (`TRADE_SOURCE_DEALER`). Хранятся только биржевые ([SPEC-0002](specs/0002-exchange-only-trades.md)). |
